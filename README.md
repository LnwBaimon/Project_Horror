# Project_Horror
คำอธิบายผลงาน
- ผลงานนี้เป็นเกมแนว Puzzle Horror ที่มุ่งเน้นสร้าง “ความรู้สึกหวาดระแวงและกังวล” โดยไม่ใช้ผีหรือ jumpscare ผู้เล่นจะต้องไขปริศนาหาของและหาทางออกจากปั้มนํ้ามันรกร้างในบรรยากาศมืดเงียบที่ไฟดับเกือบทั้งหมด
- ฉากในเกมถูกออกแบบมาเป็น เขาวงกตซับซ้อนโดยแต่ละห้องจะต่างกัน
